# QQ 联系方式文件夹

这个文件夹用于存放你的 QQ 号配置和二维码图片。

## 使用方法

### 1. 填写 QQ 号
打开同目录下的 `qq-config.js`，把 `qqNumber` 的值替换为你的真实 QQ 号：

```js
window.QQ_CONFIG = {
  qqNumber: '123456789',   // ← 改成你的 QQ 号
  ...
};
```

### 2. 放入二维码图片
把你的 QQ 二维码图片命名为 `qq-qrcode.png`，放到本文件夹（`assets/qq/`）下。

> 二维码图片获取方式：在手机 QQ → 个人资料 → 我的二维码 → 保存图片。

### 3. 验证
刷新网站，右上角会出现 QQ 按钮，点击即可看到你的 QQ 二维码和 QQ 号。

## 文件说明

| 文件 | 作用 |
|------|------|
| `qq-config.js` | QQ 号、图片路径、提示文字的配置文件（需修改） |
| `qq-qrcode.png` | 你的 QQ 二维码图片（需自行放入） |
| `README.md` | 本说明文档 |

## 注意

- 图片不存在时，弹窗会显示占位提示，不会报错。
- 改完 `qq-config.js` 后刷新页面即可生效，无需重启服务器。
- 部署到 GitHub Pages 时，整个 `assets/qq/` 文件夹会一起上传。
